# instagram-reels-bot
This is a mini Python automation project that uses Selenium to open Instagram Reels in a small side window and automatically watch and scroll reels. The script detects reel duration, waits for it to finish, and then moves to the next reel. It allows users to continue working (like coding) while reels play in the background.

Features
• Automatic Instagram login support
• Mini side window for reels playback
• Detects reel duration and waits accordingly
• Automatically scrolls to next reel
• Built using Python and Selenium


Tech Stack
Python
Selenium
Chrome WebDriver
PyInstaller
